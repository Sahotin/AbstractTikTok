# Portfolio Asset Checklist

This directory intentionally contains no screenshots yet. Capture screenshots from a local, authorized demo after configuring your own environment.

Suggested files:

- `collection-to-analysis.png` — completed collection action and analysis handoff;
- `history-analysis.png` — data management selection for a historical collection;
- `dashboard-snapshot.png` — aggregate counts, versions and topic/risk cards;
- `agent-tool-trace.png` — a scoped question with read-only tool trace.

Before adding an image, verify that it contains no API key, cookie, account identifier, full raw comment text, private URL or provider billing data. Caption Agent screenshots as **“Local Tool-Calling Validation”** unless a fresh real-provider run has been independently validated.
